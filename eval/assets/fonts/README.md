# Font dùng cho PDF tiếng Việt

`NotoSans-Regular.ttf` được giữ nguyên từ kho chính thức [notofonts/noto-fonts](https://github.com/notofonts/noto-fonts/blob/main/hinted/ttf/NotoSans/NotoSans-Regular.ttf), tải ngày 2026-11-01. Giấy phép SIL Open Font License 1.1 đi kèm trong `OFL.txt`. Font được lưu trong repo để generator không phụ thuộc font cài trên máy; PDF nhúng subset và bảng ToUnicode để hiển thị, sao chép và trích xuất dấu tiếng Việt.
